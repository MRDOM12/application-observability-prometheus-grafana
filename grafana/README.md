# Grafana Dashboard

This directory contains the exported Grafana dashboard for the Application Observability and Automated Alerting project.

## Dashboard Features

- HTTP Request Rate
- HTTP Error Rate
- Active HTTP Requests
- Average Request Latency
- P95 Request Latency

## Data Source

Prometheus

## Dashboard Refresh

5 seconds

## Import Instructions

1. Open Grafana.
2. Navigate to Dashboards.
3. Select Import.
4. Upload the dashboard JSON file.
5. Select your Prometheus data source.
6. Import the dashboard.
